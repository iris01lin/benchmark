# benchmark
There are two types of frameworks. Please refer to the corresponding folder
- pytorch (Intel Gaudi HPU)
    - basic: 2 layers of CNN with MNIST dataset
    - resnet: ResNet101 with MNIST or Food101 dataset
    - unet: Unet
- tensorflow (NVIDIA GPU)
    - basic: 2 layers of CNN with MNIST dataset
    - resnet: ResNet101 with cats_vs_dogs dataset
